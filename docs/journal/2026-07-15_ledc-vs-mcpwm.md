# 작업 일지 - 2026-07-15 : FOC PWM 페리페럴 선택 (LEDC vs MCPWM)

맨땅 FOC 구현(`components/foc/`)에서 3상 PWM을 무엇으로 만들지 결정한 기록.
결론: **LEDC 채택.**

## 배경

ESP32는 PWM 발생 페리페럴이 두 개다.

| | LEDC | MCPWM |
|---|---|---|
| 원래 용도 | LED 디밍 | Motor Control PWM |
| 데드타임 | 없음 | 있음 (하이/로우 동시 도통 방지) |
| 상보(complementary) 출력 | 없음 | 있음 (6-PWM) |
| 구현 난이도 | 쉬움 | 복잡 |

이름만 보면 모터엔 MCPWM이 정석이다. 그런데도 LEDC를 골랐다.

## 선택 근거

### 1. 드라이버가 3-PWM 입력이다
- SimpleFOC Mini = **DRV8313** 기반 **3-PWM** 게이트 드라이버.
- 우리는 IN1/IN2/IN3에 신호 **3개만** 주면 된다.
- 하이/로우 게이트 스위칭과 **데드타임은 드라이버 칩이 내부에서 처리**한다.

### 2. MCPWM의 강점이 여기선 불필요
- MCPWM의 핵심 이점 = 데드타임 + 6-PWM 상보 출력.
- 이건 게이트 6개(하이/로우)를 **MCU가 직접** 제어하는 드라이버(예: DRV8301, 개별 MOSFET 하프브릿지)에서 필요한 기능.
- 우리 구성(3-PWM 드라이버)에선 쓸 일이 없다.

### 3. LEDC로 성능 충분
- 짐벌 모터(2804) FOC는 스위칭 20kHz, 12bit 해상도로 충분.
- `80MHz / 4096 ≈ 19.5kHz` — 12bit에서 낼 수 있는 최대 주파수와 딱 맞음.
- 가청(~20kHz) 위라 모터 소음도 안 들림.

### 4. 구현이 단순
- LEDC = 타이머 1개 + 채널 3개 등록이 끝.
- 3채널이 같은 타이머를 공유해 위상 동기.

## 결론

**3-PWM 드라이버(SimpleFOC Mini)를 쓰므로 데드타임/상보출력이 필요 없고, LEDC의 단순함이 이득.**
MCPWM은 게이트를 직접 6개 제어하는 구성으로 갈 때 재검토.

## 참고
- 구현: `components/foc/foc.c` (`foc_init` LEDC 3채널 설정)
- LEDC ≠ LED 전용. duty 조절 가능한 범용 PWM 발생기.
