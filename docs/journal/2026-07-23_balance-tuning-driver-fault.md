# 2026-07-23 : 밸런싱 튜닝 진행 + SimpleFOC 드라이버 고장

토크모드 밸런싱을 튜닝하던 중 드라이버가 고장나 중단. 현재 상황 기록.

---

## 진행 상황 (동작 검증됨, 전부 커밋)
- FOC 정렬 d축 교정 + 인코더 버스트 → 커뮤테이션 정상
- 자이로 + 상보필터 각도 추정 (똑바로=0, wrap 제거)
- 토크모드 상태피드백 `uq = K1·angle + K2·rate`
- 밸런스 setpoint 캘리브레이션 (시작 시 밸런스 자세 잡고 2초 → 그 각도를 0 기준)
- 각도 데드밴드 (±1°)

## 튜닝 상태 (미완)
- **중앙에 두면 ~1초 균형 유지하나, 혼자서 넘어짐** → 안정성/튜닝 문제 (모멘텀 한계 아님).
- 게인 K1=-2.0, K2=-0.2 까지 올림. 여전히 발산.
- 미검토: 데드밴드가 오히려 무복원 데드존→드리프트 유발 가능(DEADBAND 0 테스트 필요), setpoint 정밀도, 적분항.

## 실패한 실험: 디커플링 (기록)
- 가설: 복원 시 "턱 넘어감"이 커뮤테이션 275Hz 한계 때문.
- 시도: FOC 커뮤테이션(인코더+토크) 매 iter, MPU/밸런싱 5 iter마다 → ~670Hz.
- 결과: **복원 개선 0 + 새 소음(시이익)** → 되돌림.
- 교훈: 벽은 커뮤테이션 속도 아님. 그리고 **공유 I2C 버스에선 인코더 고속 읽기가 mux/MPU와 경합**해 고속 커뮤테이션 자체가 어려움(인코더가 SPI/ABZ 등 I2C 밖이어야 가능 = 하드웨어).

---

## 하드웨어 고장: SimpleFOC Mini 드라이버 사망

### 증상 진행
- 튜닝 중 모터가 점점 약해지고 "쉬이익" 소음.
- 손으로 돌리면 매끄러움(기계 정상), 구동하면 토크 거의 없고 진동만.
- 오픈루프/정적벡터 테스트에서 3상 출력이 3.5V→하나 0→**셋 다 0** 으로 죽음. 모터 정지.

### 부품별 판정
| 부품 | 상태 | 근거 |
|---|---|---|
| 모터 | **정상** | 3상 저항 20Ω 균등, 손회전 역기전력 3상 균등 발전 |
| 배선 | **정상** | 3상 도통 OK, 고정됨 |
| ESP32 | **정상** | 코드 계속 실행 |
| **드라이버(SimpleFOC Mini)** | **사망** | 3상 출력 전부 0V, 스위칭 불가 |

### 원인 (불확실)
- 초기엔 과전류(UQ_LIMIT 11V) 의심했으나, **모터 저항 20Ω → 11V에서도 ~0.55A** 로 낮음. 과전류 단독으론 설명 약함.
- 복합 추정: marginal 드라이버 + 누적 스트레스(부팅마다 정렬 d축 전압 3.6초 홀드, 디커플링 stutter 오정렬 전류), 마지막 정적홀드 진단이 잔명을 끊었을 수 있음.
- 정확한 사인 미상. **다음엔 전압모드 전류 안전(정지 시 I=uq/R) 반드시 고려.**

---

## 다음 작업 (드라이버 교체 후)

### 재발 방지 먼저 (코드)
1. **`UQ_LIMIT` ≤ 4V로 복귀** — 정지 시 uq/R 전류를 드라이버 정격 안으로.
2. **정렬 후 캘리브레이션 중 모터 끄기** — 지금은 정렬 d축 전압을 캘리브레이션 내내 홀드(불필요 발열).

### 튜닝 재개
3. 게인 튜닝: 우선 **DEADBAND 0**으로 순수 K1·angle+K2·rate 안정성 확인 → K2(감쇠) 위주 튜닝 → setpoint 정밀도.
4. 여전히 발산이면: 적분항 / 휠속도항(K3) 검토, 상보필터 계수·지연 점검.

### 상태
- 코드는 **fcf9d27** 에 밸런싱 동작 상태로 커밋됨. 드라이버만 오면 그 지점부터 재개.
- 어려운 부분(I2C 버스 멈춤, FOC 커뮤테이션, 밸런싱 제어 아키텍처)은 전부 해결·보존됨.
