## 선정 근거

### 메인보드 — ESP32 D1 Mini Live
- 센서/제어/통신 태스크 분리를 위해 듀얼코어 필요
- FreeRTOS 내장
- WiFi/BLE 내장(정확한 자세 제어를 위해 무선으로 제어)

### FOC 드라이버 — SimpleFOC Mini
- 빠른 구현을 위해 SimpleFOC 라이브러리 사용

### 멀티플렉서 — PCA9548A
- I2C 주소 충돌 해결을 위해 사용.
- MPU6050(가속도센서)를 3개 사용하기 위함.(기존엔 할당 가능한 주소가 부족함)

### 가속도센서 — MPU6050 x3
- 로봇 자세 측정용.
- 결함 내성을 위해 3개 사용.

### 자기인코더 — MT6701
- 모터 각도 측정용

### 전압 스텝다운 — MP1584
- 배터리(11 ~ 12.6V) → ESP32·센서(3.3V/5V) 전압 강하용

### 모터 — 2804-100KV 브러시리스
- 밸런싱 휠 동작을 위해 고토크 모터 사용(100KV)

### 배터리 — 3S Lipo 3000mAh
- 모터 정격 전압/전류에 맞춤.
- 밸런싱 순간 토크(피크 전류) 대응.
- 500mAh로 충분하나, 테스트/튜닝 반복을 위해 고용량 선택

### 기판 — 단면 만능기판 7x9cm 2.54mm
- PCB에 비해 배선 검증, 수정이 자유로움
- 필요시 커팅해 사용 가능

### RLC / 기타
- **세라믹 0.1uF:** IC 디커플링(고주파 노이즈 제거)
- **전해 1000uF:** 모터 피크 전류 시 전압 강하 방어
- **저항 2.2k:** I2C 풀업 / 분압.
- **저항 330:** LED 전류 제한.
- **LED 적/녹/청:** 상태 표시(전원/동작/에러). 디버깅 가시성.

### 프레임
- 9600 레진 재질로 3D프린팅하여 조립
- 실내 사용, 프로토타입 검증 목적, 비용을 고려했을 때 적합한 재질이라고 판단함
